# Product Context

## Register

**Product** — interactive learning tool where design serves clarity and retention, not decoration.

## Target Users

Beginner Python students working through Angela Yu's 100 Days of Code (Days 1–12). Often studying on laptop or tablet, revisiting topics before assessments, building projects from scratch.

## Brand Personality

- **Clear** — hierarchy makes it obvious what to read vs. what to do
- **Encouraging** — progress visible, feedback immediate, no harsh failure states
- **Focused** — calm surfaces, readable type, code blocks that stand out
- **Trustworthy** — complete coverage, no gimmicks

## Anti-References

- Generic dark-mode dashboards with purple gradients
- Glassmorphism and neon glow everywhere
- Card grids stacked on card grids with no rhythm
- Inter/Roboto/system-ui-only typography
- Emoji-heavy navigation without structure

## Design Principles

1. **Read first, interact second** — lesson content gets the best typography; quizzes are clearly separated.
2. **One primary action per block** — each quiz has one obvious "Check" path.
3. **Progress is motivating, not noisy** — subtle completion badges, steady progress bar.
4. **Code is sacred** — monospace blocks with strong contrast and comfortable line height.
5. **Accessible by default** — focus rings, reduced motion, sufficient contrast (WCAG AA).

## Goals

Help students master Days 1–12 in 7 days and pass an assessment with 80%+ confidence.
